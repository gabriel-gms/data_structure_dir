# Data Structures

A collection of classic data structures implemented in JavaScript for educational purposes. Each implementation focuses on clarity, simplicity, and standard operations, making it a practical reference for studying how these structures work under the hood.

## Contents

> _More structures coming soon_

- **Recursion** — `recursion.js`

## Why this repository?

The best way to understand a data structure is to build it yourself. This repo provides clean, minimal implementations you can read, run, and experiment with. Each file is self-contained and can be studied independently.

## Prerequisites

- **Node.js** (v12 or later) — to run the JavaScript files
- A text editor or IDE of your choice
- Basic familiarity with JavaScript syntax (variables, functions, arrays, objects)

## Getting Started

1. **Clone the repository**

   ```bash
   git clone <repo-url>
   cd data_estructure_dir
   ```

2. **Run a file**

   ```bash
   node recursion.js
   ```

3. **Experiment** — modify the code, add your own test cases, and see how things work.

## Structure

Each file follows a consistent pattern:

- Implementation of the data structure or algorithm
- Usage examples / test cases at the bottom of the file

You can run any file directly with Node.js — no build step or dependencies required.
